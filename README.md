# Priyanshi Agarwaal

Portrait gallery site. Fresh project — no shared code or assets with other sites.

## Stack

- Next.js + Tailwind v4
- Deploy: Vercel (1648)

## Images

1. Drop files into `public/images/`
2. Register them in `lib/photos.ts`
3. Push — Vercel rebuilds

## Dev

```bash
npm install
npm run dev
```
