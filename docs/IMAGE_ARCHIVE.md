# Image archive — Priyanshi Agarwaal

All generated and source images live under `public/images/` so they ship with every Vercel deploy and GitHub push.

## Layout

| Path | Contents |
|------|----------|
| `public/images/*.jpg` | Original 7 Grok Imagine frames + 12 fashion gens |
| `public/images/architecture/` | Face / body / expression / lighting sheets |
| `public/images/mapping/orbit/` | 12 orbit turntable frames (`orbit-000`…`330` + raw copies) |
| `public/images/mapping/poses/` | Pose atlas drafts (stand, walk, sit-chair, sit-ground) |
| `public/images/generated/` | Working copies of fashion waves (backup) |
| `public/images/archive/session/` | Full session dump `session-01`…`session-32` |
